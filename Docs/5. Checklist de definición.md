## Nota metodológica

Este checklist no busca ser respondido de una sola vez. La idea es:

1. Revisarlo juntos y priorizar qué categorías cerrar primero.
2. Decidir el nivel de detalle necesario para cada aspecto (algunos pueden resolverse sobre la marcha durante la implementación).
3. Marcar como ✅ solo lo que esté suficientemente definido para que la implementación no tenga ambigüedades.
